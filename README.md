# ComfyUI AI Prompt Studio

AI 提示词工作室 —— 面向 ComfyUI 的 LLM 提示词工作流扩展。

> 占位 README：完整中文文档（安装/配置/节点说明/示例）在 Phase 6 补齐。

## 定位

覆盖并改进 PromptForge 的主要能力，支持：

- DeepSeek Responses API / Chat Completions / 原生联网搜索
- 任意 OpenAI 兼容端点（含视觉模型）
- 本地 LLM 运行时（Ollama / llama.cpp / LM Studio）加载与卸载
- 文本与图片人物锚点、多图特征反推与共识合并
- 剧情分镜
- ANIMA Base / Aesthetic / Turbo 提示词
- MiniMax H3 T2VA / I2VA / FL2VA / L2VA / R2V 提示词
- 提示词生成、改写、审计和修复
- 模型能力探测与显存交接

## 节点

9 个节点，统一分类 `AI Prompt Studio`。详见 Phase 6 的节点文档。
