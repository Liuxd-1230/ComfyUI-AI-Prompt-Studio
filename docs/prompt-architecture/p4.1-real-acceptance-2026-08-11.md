## Defects found and closed during the run

The live run exposed invalid nested ChangeSet paths, a first-shot `00:00.000`
timestamp, pan/truck mistranslation, and an invented second shot despite an explicit
single-shot request. Production now enumerates exact Plan mutation paths, normalizes
Shot 1, enforces camera vocabulary, and rejects `[Shot 2]` for explicit one-shot tasks.

## Remaining live-injection boundary

Two attempts asked the local model to emit a partial tag or truncated JSON response.
It instead returned a valid untagged English prompt, so an actual malformed LM response
was not observed in this environment. No test-only production switch was added.
The one-retry/no-commit behavior remains covered through the public node/Gateway seam
by deterministic regressions; this single provider-dependent live case is not claimed
as completed.
