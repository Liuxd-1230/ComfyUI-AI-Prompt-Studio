# 提示词边界与工作流全连接验收

本页是可重复执行的验收说明。机器可读矩阵位于 `examples/acceptance/prompt_matrix.json`，覆盖当前全部公共下拉模式，以及节点包内部所有类型兼容的输出→输入连接。“跑通”指节点产生可供下游使用、且通过本包校验的 Prompt；不包含耗时的图像/视频生成模型。

## 统一测试素材

人物锚点：`Rose, long wavy black hair, amber-green eyes, ivory Victorian rose dress with black floral sash.`

图像任务：`Rose reads a blank unmarked letter beside a rain-covered train window; medium shot, cool light; preserve identity and add no visible text.`

H3 任务：`Create an English cinematic prompt. Rose stands in a sunlit vintage train carriage, opens a blank unmarked letter, then looks toward the window. Preserve her identity and dress. No dialogue. Natural carriage ambience, no music.`

分镜任务：`林澈，黑色短发，琥珀色眼睛，深蓝长风衣。她在雨夜车站捡起一封信，抬头看见列车驶来。`

## 全模式效果矩阵

| 节点 | 组合 | 期待效果 |
|---|---:|---|
| Image Prompt Studio | 6 targets × lenient/strict = 12 | ANIMA 输出英文；Z-Image、Qwen Edit 和 Generic 保留目标语义及 Figure 引用；严格模式通过结构化校验 |
| H3 Prompt Studio | 5 modes × lenient/strict = 10 | T2VA 无图片；I2VA 首帧；FL2VA 首尾帧；L2VA 尾帧；Ref2VA 六段协议、官方标签和 retention |
| Reference Analyzer | 11 modes | 10 个内置模式均有专属观察边界；custom 必须填写指令 |
| Character Bible | 5 merge strategies | 锁定事实永不覆盖；其余按 text/image/consensus/fill-missing 规则合并 |
| Storyboard Builder | scene/shot/beat/auto | 生成模型无关的场景、镜头或节拍结构 |
| Storyboard Select | scene/shot/range/all | 均返回一个 `STORY_ITEM`；批量口同时返回所选列表 |
| LLM Generate | 3 output × 3 history | text/json/json_schema 与 append/replace/off 均为公开合同 |

## 全部合法连接方法

以下是 35 条精确端口连接的分组表示。测试从 `INPUT_TYPES`/`RETURN_TYPES` 动态发现端口，并要求机器矩阵完全一致；新端口漏记会直接失败。

- `ModelProfile.AI_PROFILE` 或 `RuntimeControl.AI_PROFILE` → LLM、Reference Analyzer、Storyboard Builder、Image Studio、H3 Studio；ModelProfile 还可接 RuntimeControl。
- `ReferenceAnalyzer.CHARACTER_CANDIDATE` → Character Bible。
- `CharacterBible.CHARACTER_BIBLE` → Character Bible、Reference Analyzer、Storyboard Builder、Image Studio、H3 Studio。
- `CharacterBible.CHARACTER_BOOK` → Character Bible、Storyboard Builder、Image Studio、H3 Studio。
- `ReferenceAnalyzer/ReferencePrompt/H3Studio.REFERENCE_MANIFEST` → Storyboard Builder、Image Studio、H3 Studio。
- `StoryboardBuilder.STORYBOARD` → Storyboard Select 或 H3 Studio。
- `StoryboardSelect.STORY_ITEM` 或批量兼容口 `STORY_ITEMS` → Image Studio `story_item`。
- `LLMGenerate.CHAT_SESSION` → 下一轮 LLM Generate `session`；Image/H3 的 `prompt_session` 接回本节点隐藏会话输入。

可导入的完整示例是 `examples/anima_full_chain.json`、`examples/h3_full_chain.json` 和 `examples/aps_usage_showcase.json`。

## 实测结果（基元档案）

2026-08-13 使用生产节点类、真实 Gateway 与“基元”档案，不连接生成模型：

- Image Studio：12/12 通过。实测发现并修复 `STORY_ITEM` 读取旧字段导致的执行错误；严格 Qwen/Generic 的 negative 输出约束也已收紧。
- H3：10/10 通过。FL2VA 严格输出连续 `Picture 1/2`；Ref2VA 严格不再泄漏 `img_0`，使用合法 `[reference generation]`，锁定 Subject 获得可证明的 retention。348 词会给“建议 350–500 词”warning，但不阻断可用 Prompt。
- LLM text 返回 3 条中文雨夜构图建议；json_schema 返回可解析的 `{"location":"上海外滩","weather":"雨"}`。
- 文字链生成 1 场、2 镜头，`all` 返回 2 个 StoryItem。
- 图片链使用 `640.jpg` 经 LM 视觉档案生成可见人物锚点、Bible 与 Manifest，再由基元档案消费。

模型输出存在随机性，因此真实测试证明当前档案/端点的实跑结果；发布门同时用确定性回归锁住协议、端口和错误边界。

## 必须明确报错的边界

“不会报错”不等于吞掉非法输入。以下必须在下游执行前给出可读错误：缺失档案或密钥；空任务；非法 target/mode；ANIMA 非英文成品；悬空 Figure/媒体标签；正负提示词真实冲突；H3 时长不在 4–15 秒；模式图片数错误；Ref2VA 超出图片 9、视频 3、音频 3、总资产 12 或视频/音频总时长 15 秒；未知媒体时长；会话指纹、revision 或锁定事实冲突。
